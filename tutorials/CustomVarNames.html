Custom Variable Names

Go back to Tutorial page

Author: Jeff Calc 84

We all love Axe. However, if there's one thing that's annoying, it's that for variables you can only use A-Z and theta. You can't use any custom variable names...
Execpt that, you can?

First, let's familiarize ourselves with the degree symbol and what it does:
+=====================================================+
|°VAR |Returns the address of the variable in memory.
+=====================================================+
See? Kinda like "&var" in C.

Now, here's the fun part:
+Axe code=================+
|L1->°Cnt
|L1+2->°Sum
|ClrHome
|0->{Cnt}
|1->{Sum}
|While {Cnt}(islessthan)100
|{Sum}++
|{Cnt}++
|Disp {Sum}
|End
|Pause 1000
|ClrHome
+=========================+
This compiles and runs correctly.
Now you know how to make custom variable names in Axe. :)
